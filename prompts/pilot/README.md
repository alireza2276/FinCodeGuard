# Pilot Candidate Prompts

These prompts are frozen inputs for the FinCodeGuard v0.1 pilot.

Rules:
- Do not show executable oracle source code to the model generating candidates.
- Use the prompt text as stored, without adding hints derived from oracle behavior.
- Save the raw model response before manually editing anything.
- Record model/provider/version/date and generation settings in metadata.
- One generated candidate belongs to one task and one recorded generation run.
